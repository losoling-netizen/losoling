1. **🌟 核心特色**
   - 👵 **樂齡友善視覺**：支援三段大字體切換（標準 18px / 放大 24px / 特大 30px）與護眼高對比卡片。
   - 🗣️ **英/美雙語音**：獨立 🇬🇧 英式發音與 🇺🇸 美式發音按鈕，支援慢速（0.78x）、舒適（0.90x）、標準（1.0x）速度與防疊音機制。
   - 📚 **四大實用主題**：生活日常、旅遊英文、餐廳英文、緊急情境（350+ 單字、700+ 情境句）。
   - 📖 **一頁一單元**：1 單字 + 2 情境例句，可個別標記學會（⭐）。
   - 📊 **進度統計與收藏**：即時掌握學習百分比，支援單元跳轉與重點複習。
   - 💾 **免伺服器運作**：使用 LocalStorage 自動儲存學習紀錄與偏好設定。

2. **🚀 快速開始**
   - 直接用瀏覽器開啟 `index.html` 即可使用。
   - 或使用靜態伺服器（`npx serve .` 或 `python -m http.server 8080`）。

3. **💡 常見問題 (FAQ) 與技術架構**
   - 說明 Web Speech API 發音疑難排解、語系挑選規則與資料儲存說明。
